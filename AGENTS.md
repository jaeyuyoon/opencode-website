# Project constraints

- Plain HTML, CSS, and JavaScript only. No frameworks, no build step, no npm packages.
- Keep the site small: `index.html`, `style.css`, `script.js`.
- Serve locally with `python3 -m http.server 8000`. Do not add deployment config.
- All content is invented. Do not add real names, emails, keys, or tokens.
- The page must work at narrow (about 360px) and wide (1200px) widths.
- All controls must be keyboard operable and show a visible focus outline.
- Text must stay readable in both the light and dark theme.
- Do not commit `node_modules/`, build output, or credentials.
- Explain any change you make before editing files.
